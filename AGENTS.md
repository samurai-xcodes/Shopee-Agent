# Shopee AI Agent Engineering Project

## Goal
Build a production-oriented AI Creative Agent
to prepare for AI Agent engineering interviews.

## Environment
- Ubuntu on WSL
- Python 3
- FastAPI
- Future: PostgreSQL, Redis, LangGraph

## Development Principles
1. Search for suitable open-source implementations
   before building complex features.
2. Prefer simple, maintainable solutions.
3. Do not introduce unnecessary dependencies.
4. Explain important architectural decisions.
5. Add tests for new features and bug fixes.
6. Run relevant tests after changes.
7. Never hardcode secrets or API keys.

## Teaching Rules
The developer has Android Framework experience
but is learning Python backend engineering.

For every task:
1. Explain the implementation plan in Chinese.
2. Identify the core concepts to learn.
3. Implement in small, reviewable steps.
4. Explain important code in Chinese.
5. Provide one interview-style question.
6. Do not make unrelated changes.
